Teilaufgabe 1¶

Residual = Residuum, d.h. die Abweichung des Ausgabewerts des Modells von dem tatsächlichen "Ground Truth" Wert:

ri=yi−f(xi1,xi2,...,xik)ri=yi−f(xi1,xi2,...,xik)

(wenn kk Features in die Regression eingehen; für eine einfache lineare Regression k=1k=1)

Regressor = die kk "Features" (d.h. kk Spalten der Datenmatrix), die Eingangsgrößen für das Modell sind (anderer Begriff: unabhängige Variablen / independent variables)

Regressand = die Zielgröße yy, die Ziel- und Ausgangsgröße des Modells ist (anderer Begriff: abhängige Variable / dependent variable)

a0 = 1.0
a1 = 1.0

def gradient_descent ( x, y, a0, a1, LR, iterations=10 ):
    n = len(y)
    a0s  = [a0]
    a1s  = [a1]
    mses = []

    for i in range(iterations):
        mse = ( (y-(a0+a1*x))**2 ).sum() / n
        mses.append(mse)

        d0_mse = -(y-(a0+a1*x)).sum()*(2/n)
        d1_mse = -((y-(a0+a1*x))*x).sum()*(2/n)

        a0 = a0 - LR*d0_mse
        a1 = a1 - LR*d1_mse

        a0s.append(a0)
        a1s.append(a1)
    
    return a0s, a1s, mses
