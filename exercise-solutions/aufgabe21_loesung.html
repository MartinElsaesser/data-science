Mit einer Dimensionsreduktion wird versucht, den Informationsgehalt hochdimensionaler Daten (d.h. viele Spalten) auf wenige Spalten abzubilden. In dieser Aufgabe soll mit t-SNE ein Vertreter der nicht-linearen Techniken untersucht werden.

  1. Laden Sie den digits Datensatz von sklearn. Beschränken Sie sich auf die Zahlen 0,1,...,5. Wenden Sie nun eine t-SNE an mit Parameter n_components=2. Visualisieren Sie die beiden neu erzeugten Spalten in einem Scatterplot und färben Sie die jeweiligen Punktpaare gemäß der auf diesem Bild dargestellten Zahl ein.
  2. Der t-SNE-Algorithmus kann mittels eines Hyperparameters perplexity im Konstruktor angepasst werden. Der Default-Wert ist 30. Erstellen Sie die Grafik aus 1. nochmals für die Perplexity-Werte 2,3,4,5,10,30,50.

from sklearn.manifold import TSNE

for perplexity in [2,3,4,5,10,30,50]:
    tsne = TSNE(n_components=2, perplexity=perplexity)
    data_trf = tsne.fit_transform( data )

    plt.scatter ( data_trf[:,0], data_trf[:,1], c=target, cmap=plt.get_cmap("tab10",6), vmin=-0.5, vmax=5.5 )
    cbar = plt.colorbar(ticks=np.arange(0,7,1) )
    plt.xlabel("erste Spalte der t-SNE")
    plt.ylabel("zweite Spalte der t-SNE")
    plt.title("Perplexity: "+str(perplexity))
    plt.show()
